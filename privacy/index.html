Política de privacidad

Esta aplicación se utiliza exclusivamente para conectar Google Calendar con una instalación privada de Home Assistant.

Datos a los que accede la aplicación

La aplicación puede acceder a la información de los calendarios de Google que el usuario autorice durante el proceso de autenticación.

Este acceso puede incluir información como nombres de calendarios, títulos de eventos, fechas, horarios y otros datos necesarios para mostrar y gestionar eventos dentro de Home Assistant.

Finalidad del acceso

Los datos se utilizan únicamente para integrar Google Calendar con la instalación privada de Home Assistant del usuario.

Almacenamiento y tratamiento

Los datos obtenidos mediante las APIs de Google no se venden, alquilan, comparten ni utilizan con fines publicitarios.

La aplicación no funciona como un servicio público ni comercial. Los datos se procesan únicamente en el contexto de la instalación privada de Home Assistant del usuario.

Compartición con terceros

Los datos obtenidos mediante Google APIs no se comparten con terceros, salvo cuando sea estrictamente necesario para el funcionamiento técnico de Google Calendar y Home Assistant.

Revocación del acceso

El usuario puede revocar en cualquier momento el acceso concedido a la aplicación desde la configuración de seguridad de su cuenta de Google.

Contacto

Para cualquier consulta relacionada con esta política de privacidad, puede utilizarse la dirección de correo electrónico asociada a la aplicación OAuth.
