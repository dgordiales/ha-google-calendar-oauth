Home Assistant Calendario

Esta aplicación se utiliza para conectar Google Calendar con una instalación privada de Home Assistant.

Su finalidad es permitir que Home Assistant consulte los calendarios autorizados por el usuario y muestre sus eventos en un panel doméstico.

La aplicación es de uso personal y no ofrece ningún servicio público ni comercial.

Uso de los datos de Google

El acceso a Google Calendar se utiliza exclusivamente para mostrar y gestionar la información del calendario dentro de la instalación privada de Home Assistant del usuario.

Los datos obtenidos mediante las APIs de Google no se venden, comparten ni utilizan con fines publicitarios.
